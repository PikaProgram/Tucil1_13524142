# Queenables
Solver for LinkedIn Queens

### Requirements
- Go

### Compiling & Running
1. Clone the repo (funny)
```
git clone https://github.com/PikaProgram/Tucil_13524142.git
```

2. Running is as simple as installing dependencies and running:

```
go mod download
go run src/main.go
```

3. And compiling is also as simple

```
go mod download
go build src/main.go
```
